OSSIO is an orthopedic fixation medical device company headquartered in Woburn, Massachusetts and founded in Israel in 2014. It develops and sells OSSIOfiber, a bio-integrative, metal-free implant material used for screws, suture anchors, staples, bone pins and trimmable fixation nails in foot and ankle, hand and wrist, sports medicine and pediatric procedures. OSSIO ships physical implants, not software, and publishes no developer program, no product API and no OpenAPI. Its one machine-readable surface is the corporate website itself: ossio.io runs WordPress with the MCP Adapter installed, exposing an OAuth-protected Model Context Protocol server plus RFC 8414 and RFC 9728 metadata documents at /.well-known/ — a site-content agent surface, not a product API.

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for OSSIO: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
